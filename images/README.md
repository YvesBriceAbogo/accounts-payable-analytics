# Power BI Dashboard Screenshots

This directory contains visual documentation of the Accounts Payable Analytics project.

The screenshots illustrate the financial dashboards and relational data model developed using Power BI Desktop.

## Dashboard Pages

- `dashboard-overview.png` — Executive Financial Overview.
- `supplier-analysis.png` — Supplier Debt and Payment Analysis.
- `monthly-performance.png` — Monthly Financial Performance.
- `invoice-details.png` — Detailed Accounts Payable Register.
- `data-model.png` — Power BI Relational Data Model.

These visualizations demonstrate financial KPI monitoring, accounts payable aging analysis, supplier reconciliation, payment forecasting, and financial data modeling.
